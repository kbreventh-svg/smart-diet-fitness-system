# Smart Diet & Fitness Recommendation System

A responsive web app that gives personalized diet and fitness recommendations from a user's profile.

## Features
- BMI calculation with colour-coded category (Underweight, Normal, Overweight, Obese)
- Daily calorie target using the Mifflin-St Jeor equation, adjusted for the user's goal
- Goal-based meal plans (lose weight, gain muscle, maintain weight)
- Fitness-level-based workout plans (beginner, intermediate, advanced)
- Water intake and sleep recommendations
- Input validation and mobile-friendly layout

## Built With
HTML5, CSS3, JavaScript (ES6+). It runs fully in the browser and needs no server.

## How to Run
Open `index.html` in any modern browser, or use the live demo link.
